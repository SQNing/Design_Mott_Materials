# 第二阶段：有对照证据的物理简化

日期：2026-10-30。继续现有 Research 工作流，完整模型始终是不可覆盖的对照。宿主 agent 提出和选择候选，软件负责忠实变换、计算、误差与适用范围记录。验证通过只覆盖实际检查的模型参数点、有限尺寸、能量窗口和观测量。

## 候选

新增 propose_reduction 动作，明确 transformation：

- drop_terms：按规范模型的 term_ref 删除指定完整项；记录原始项和系数。候选必须再次通过完整结构对称性检查，不自动降群或平均修复。
- project_local_space：提供同一局域空间的列正交 isometry，生成压缩的 onsite 和一般 pair operator，更新局域维数、基底标签和对称表示。检查子空间对称性封闭。此变换是直接子空间投影，不包含虚激发产生的高阶有效相互作用。

局域维数截断保留 isometry 和每个原算符到候选算符的映射；不把任意保留态猜成物理自旋。非 Hermitian 输入、不正交嵌入、不支持的高体项和不封闭子空间明确失败。完整模型及原始数据不变。

## 对照验证

新增 calculate/task=reduction_validation，通过同一个 worker、预算和报告流程执行。设置包含 candidate_id、实验列表、逐项容差和（投影时必须有的）低能窗口。每个实验指定 case_id、task、settings、metrics，谱实验指向一个经典态实验作为参考。

默认完整检查至少覆盖经典态和谐波/有限簇低能谱；可加入已有 MC，但未经平衡性验证的结果不能让候选通过。容差必须明确给出，不把系数占比当成物理容差。

比较内容：

- 同一有限原胞归一化的能量，允许明确声明的常数能量偏移。
- 把候选最优态嵌回完整模型，计算其能量惩罚。若候选态在完整模型中比“完整模型参考”更低，说明对照搜索不足，应补算而不是认证候选。
- 自旋的成对相关量；保留局域态使用投影后的密度矩阵距离，避免将整体相位当作物理差异。不同对称等价代表仍可能需要宿主进一步检查，不能把一次构型比较扩展成全相图结论。
- 同样波矢、同样磁超胞的低能谱。投影导致模式数变化时，只比较明确窗口内模式，并检查窗口边界；边界模糊或模式数不一致不能静默匹配。
- 已支持的有限量子簇低能间隙及残差。MC 保留统计误差和未证实的平衡性。

输出 validation_status 为 accepted_within_scope / rejected / inconclusive。具有可靠反例的 rejected 也是可用于回答问题的科学证据；execution_status、scientific_status 与验证结论分开。

## 状态与预算

候选保存在 reductions/ID，绑定完整模型身份。原模型修改后旧候选不可用于新模型。比较的每个真实求解调用都计入预算；不会把一组十次求解算成一次。完整模型与候选的相同子实验按模型、设置、参考和代码环境身份复用。仅修改比较容差无需重算物理。

报告读取候选、全部误差、失败理由、证据路径与检查范围，不启动求解。不会自动以候选替代用户模型。

## 实施顺序与验收

1. scripts/research/reductions.py：候选变换与记录；测试原模型不变、投影矩阵元、对子空间和对称性的拒绝。
2. scripts/research/reduction_validation.py：实际对照计算、态嵌入、观测量和谱比较、有效范围；复用现有数值内核。
3. scripts/research/workflow.py / adapters.py / state.py：新动作、worker 路由、真实求解预算、子实验复用和恢复。
4. scripts/research/report.py、SKILL 和 reference：报告、使用协议和可复跑示例。
5. 实际验收：弱项可接受；“小系数但关键”的项被拒绝；三能级到两能级的有效投影；不合适投影/低能窗口失败；不足预算/不合格参考为 inconclusive；重复验证不额外求解；阶段一回归。

第二阶段不承诺自动 Schrieffer-Wolff 展开、无限系统误差界、普遍相等价证明或任意后端支持。它把可以验证的物理近似及其证据接入产品。
