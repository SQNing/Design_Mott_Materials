# 第三阶段：机制干预与可追溯物理解释

日期：2026-10-30。继续前两阶段的 Research 工作流。在已明确的完整哈密顿量上提出可检验的机制假设，构造改变指定相互作用强度的对照，计算观测量响应，并生成带证据、限制和下一步建议的解释。

## 本阶段边界

本阶段检验“哪组相互作用控制某个已定义观测量”的模型内机制。支持逐组关闭、增强、减弱及多个显式强度点。保留完整模型；每个干预点都重新接受原结构对称性检查。不会把小系数、一次相关性或一次数值失败当作机制证据。

不自动做 Schrieffer-Wolff 展开、虚激发修正、无限体系证明或普遍因果推断。多项同时变化但缺少逐组对照时，针对单项的机制判断为 inconclusive。阶段二近似的有效范围不会自动扩展到干预后的新模型。

## 接口

新增 propose_mechanism 动作，保存 mechanism_id、非空 question、groups 与 points：

- groups：互不重叠的 term_ref 列表，每组有 group_id 和物理说明。
- points：明确给出每组的有限实数乘因子、point_id；必须恰有一个全为 1 的完整模型对照。0 表示关闭，保留项的表示与来源。
- 任何未知项、重复分组、重复强度点、非有限系数或不满足结构对称性的点，都不得作为完整的可计算计划启动。

新增 calculate/task=mechanism_test，settings 含 mechanism_id、experiments、observables、hypotheses 及数值控制容差。

- experiments 复用已接通的经典态、谐波谱、有限量子簇；谐波谱逐点引用同一组经典实验。MC 保留原有科学不确定性。
- observables 明确定义要比较的标量：每原胞经典能量、指定波矢的排序谐波频率、指定有限量子能级间隙、局域保留态占据。
- hypotheses 关联一个观测量和一个干预组；支持有最小效应要求的单调响应、在其余耦合固定时关闭该组是否消除指定现象、以及给定容差内不敏感。
- 单调判断至少要求三个可识别的强度点；现象必要性要求完整对照及关闭点，且完整模型确实表现出该现象；其它组必须保持对照值。边界不清、输入范围不足或数值控制不合格都返回 inconclusive。
- 结论为 supported_within_scope / refuted_within_scope / inconclusive。可靠反证可作为科学可用的回答；任何未解决的请求假设使整项科学状态保持 inconclusive。

## 能量与状态诊断

对于每个经典实验，在同一超胞比较完整参考态和干预后优化态：

1. 完整模型参考能量。
2. 完整参考态在干预哈密顿量中的能量。
3. 干预后优化态在干预哈密顿量中的能量。
4. 干预后优化态放回完整哈密顿量的能量。

因此可区分固定态下的直接能量变化与态重新优化造成的能量变化。若已有态能降低另一边声称的“最优”能量，说明搜索对照不足；对应经典观测量及其依赖谱不可用于支持或反驳机制。能量评估复用现有内核，不另造求解器，不计为新的优化调用。

## 执行、证据和预算

提取第二阶段已有的子实验计划与执行逻辑为共享模块，保持既有数值指纹和缓存格式；两阶段共用经过内容摘要验证的证据。每个不同模型、实验和参考的真实求解分别计入预算，启动前预留未缓存调用。仅改变观测量或假设阈值可复用物理计算；失败不缓存为成功。

每个结果保存原始观测量、逐项判据、结果路径、真实使用的有限胞、波矢、强度范围、基底语义与假设文字。报告只读取证据，逐条展示假设与支持/反驳理由。宿主 agent 再据此作 assess，不把 worker 完成等同于问题解决。

## 文件与实施顺序

1. scripts/research/mechanisms.py：干预计划、系数变换、模型身份与结构对称性检查。
2. scripts/research/experiments.py：共享子实验指纹、预算、缓存、引用与执行；保持阶段二行为。
3. scripts/research/mechanism_analysis.py：观测量提取、交叉能量评估、假设检验与解释证据。
4. workflow.py、adapters.py、worker.py、report.py：新动作与任务、状态与报告接入。
5. tests/test_mechanisms.py 与 run_mechanism_acceptance.py：实际物理例、故障边界、复用、接续与报告。
6. reference/mechanism-workflow.md、SKILL.md 与验收记录：调用协议与已验证范围。

## 验收

- 普通自旋：小各向异性控制所采样的低能频率；增强/减弱/关闭的证据支持正确假设。
- 替代机制：相同背景中某组交换对该频率不敏感；错误的主导假设被反驳。
- 保留局域三能级：现场能级与一般 pair operator 的相应干预，完整局域维数不变，得到可解释的频率/占据响应。
- 缺少单因素对照、只有两个单调采样点、阈值边界或不合格参考都保持 inconclusive。
- 完整模型不变；结构对称性破坏拒绝；预算按实际调用；相同物理不同假设不重复计算；跨进程接续无重复 worker；报告不计算。
- 运行阶段一、阶段二与相关共享层回归。实际工作流另存不可覆盖的验收目录。
